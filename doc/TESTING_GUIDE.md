## 📋 測試步驟

### 1. 啟動 Obsidian 並載入插件
1. 打開 Obsidian 應用程式
2. 打開你的 vault（或創建一個測試 vault）
3. 前往 **設置** → **第三方插件**
4. 找到 **"Window Spaces"** 並點擊啟用開關
5. 重新啟動 Obsidian（如果需要）

### 2. 基本功能測試

#### 測試 A：保存佈局
1. 在 Obsidian 中打開一些文件（2-3 個）
2. 使用 **Ctrl+P** 打開命令面板
3. 輸入 **"保存當前視窗佈局"** 並執行
4. 在彈出的對話框中輸入佈局名稱，例如 **"測試佈局 1"**
5. 點擊 **"保存"** 按鈕
6. ✅ 應該看到成功通知

#### 測試 B：恢復佈局
1. 關閉一些文件或改變佈局
2. 使用 **Ctrl+P** 打開命令面板
3. 輸入 **"恢復視窗佈局"** 並執行
4. 從列表中選擇剛才保存的 **"測試佈局 1"**
5. ✅ 應該看到佈局被恢復

#### 測試 C：管理佈局
1. 使用 **Ctrl+P** 打開命令面板
2. 輸入 **"管理視窗佈局"** 並執行
3. ✅ 應該看到設定頁面中的佈局管理界面

#### 測試 C-1：Panel Toolbar 位置一致性
1. 同時開啟 Obsidian 內建 **File Explorer**、Window Spaces Editor Tab，以及 Window Spaces Right Sidebar。
2. 確認三個區域的 toolbar 都從各自 leaf 的相同頂端開始。
3. 確認 Editor Tab 與 Right Sidebar 的 Window Spaces toolbar 按鈕順序、置中位置、邊框與上下 padding/margin 一致，且與 File Explorer 的 toolbar 高度對齊。
4. 將 Window Spaces 從 Editor Tab 改開至 Left Sidebar，再重複檢查；不應出現位置專用的排列差異。
5. 若修改 toolbar CSS，完成 Obsidian 完整重啟後再驗收，避免舊版 `styles.css` 快取造成誤判。

### 3. 進階功能測試

#### 測試 D：設定頁面
1. 前往 **設置** → **Window Spaces**
2. 測試各種設定選項：
   - 顯示通知開關
   - 自動保存開關
   - 最大佈局數量調整
3. ✅ 設定應該能正常保存

#### 測試 E：快速恢復命令
1. 保存多個佈局後
2. 使用 **Ctrl+P** 搜索 **"恢復佈局:"**
3. ✅ 應該看到每個保存佈局的專用命令

### 4. 邊界情況測試

#### 測試 F：空佈局列表
1. 刪除所有保存的佈局
2. 嘗試恢復佈局
3. ✅ 應該顯示適當的空狀態訊息

#### 測試 G：無效佈局
1. 嘗試恢復不存在的佈局
2. ✅ 應該顯示錯誤訊息

## 🔧 故障排除

### 常見問題

**Q: 插件沒有出現在設置中**
A: 檢查文件是否正確複製到插件目錄，重新啟動 Obsidian

**Q: 命令沒有出現在命令面板中**
A: 確保插件已啟用，嘗試重新載入 Obsidian

**Q: 保存/恢復失敗**
A: 檢查開發者控制台（Ctrl+Shift+I）查看錯誤訊息

**Q: 佈局恢復不完整**
A: 確保在彈出視窗中保存佈局，而不是主視窗

### 調試模式
1. 按 **Ctrl+Shift+I** 打開開發者工具
2. 查看 Console 標籤
3. 搜索 "Window Spaces" 相關的日誌
4. 報告問題時包含相關的錯誤訊息
