# 專案文件

## 文件分類

- `AGENT_TODO.md`：可由 Agent 逐項執行與驗收的產品改善待辦事項。
- `PLANNING.md`：原始開發規劃。
- `TESTING_GUIDE.md`：功能測試步驟與檢查清單。
- `I18N_TESTING_GUIDE.md`：多語言測試指南。
- `SESSION_STATUS.md`：歷次修正與測試狀態。
- `DEVELOPMENT_SUMMARY.md`：開發摘要。
- `IMPROVEMENT_ITEMS.md`、`CODE_REVIEW_AND_FIX_PLAN.md`：歷史問題與修正計畫。
- `session-*.md`：歷史工作階段紀錄。

## Agent 工作規則

開始改善功能前，先在 `AGENT_TODO.md` 找到對應項目；完成後更新狀態、驗收條件與測試結果。若需求超出原項目範圍，新增一個有編號的 TODO，不要只留下未追蹤的臨時修改。
