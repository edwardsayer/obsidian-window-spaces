## 🚀 使用方法

### 快速開始
1. **構建插件**：`npm run build`
2. **安裝插件**：`npm run install:vault`
3. **啟用插件**：在 Obsidian 設置中啟用
4. **使用功能**：通過命令面板 (Ctrl/Cmd + P) 搜索 "Window Spaces"

### 核心操作
- **保存佈局**：在目標視窗中執行 "保存當前視窗佈局"
- **恢復佈局**：執行 "恢復視窗佈局" 並選擇保存的佈局
- **管理佈局**：執行 "管理視窗佈局" 進行高級管理
